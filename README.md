# Nirmal Kumar P R — AI Engineer & Software Developer Portfolio

A modern, immersive, interactive personal portfolio website for **Nirmal Kumar P R**, Junior AI Engineer & Software Developer.

Live website showcasing expertise across Generative AI, LLM Applications, Retrieval-Augmented Generation (RAG), AI Agent Architectures, Intelligent Automation, and Full-Stack Engineering.

---

## ⚡ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React 19 framework)
- **Runtime & Bundler**: [Vite](https://vitejs.dev/) + [Nitro](https://nitro.unjs.io/) (Cloudflare preset)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & Motion**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger), [Lenis](https://lenis.darkroom.engineering/) (Smooth Scroll), [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **Components**: [Radix UI](https://www.radix-ui.com/), Lucide Icons, Simple Icons
- **Language**: TypeScript

## 🛠️ Getting Started

### Prerequisites

- Node.js (>= 20) or [Bun](https://bun.sh/)
- npm / pnpm / bun

### Installation

Clone the repository:

```bash
git clone git@github-personal:PrNirmal/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm install
# or
bun install
```

### Development Server

Start the local Vite development server:

```bash
npm run dev
# or
bun run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
